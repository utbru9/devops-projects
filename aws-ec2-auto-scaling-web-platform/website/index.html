About the simulation

The CloudCart storefront represents an e-commerce workload that receives increased traffic during a promotional sales period.

The infrastructure project demonstrates load balancing, health monitoring, automatic scale-out, automatic scale-in and unhealthy-instance replacement. Products, prices, orders, payments and delivery details are fictional.
